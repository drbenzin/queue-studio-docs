# Queue Studio for Service Bus — Support

- **Bugs and feature requests:** [GitHub issues](https://github.com/drbenzin/queue-studio-docs/issues). Please
  include the VS Code version, the extension version, the connection type (connection string, Entra ID or
  emulator) and the error text. Never paste connection strings, message contents you cannot share or license keys:
  issues are public.
- **Anything private, including licenses and refunds:** factodus@gmail.com.
- **Payments, invoices, cancellation:** the [customer portal](https://polar.sh/factodus/portal) or the link in your
  Polar receipt email. Polar, the merchant of record, also answers at support@polar.sh.
